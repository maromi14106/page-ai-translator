# Page AI Translator

FirefoxのサイドバーからWebページをAI翻訳するWebExtensionです。

OpenAI APIとローカルOllamaに対応し、ページ全体の翻訳、選択範囲翻訳、
複数言語、翻訳ルール、原文/翻訳文の切り替え、永続キャッシュを利用できます。

## インストール

Firefox Add-onsからインストールできます。

[Page AI Translator - Firefox Add-ons](https://addons.mozilla.org/addon/page-ai-translator/)

## 主な機能

- Webページ全体のAI翻訳
- 選択範囲のみの翻訳
- OpenAI API / ローカルOllama
- 日本語、英語、韓国語、中国語（簡体字・繁体字）、フランス語、ドイツ語、スペイン語
- 翻訳スタイル・専門用語ポリシー・カスタム指示
- 原文 / 翻訳文の即時切り替え
- 翻訳キャッシュとキャッシュ管理
- 動的ページ内容の検出
- `Ctrl + Shift + .` でサイドバーを開閉

## プライバシー

OpenAIモードでは、翻訳対象の文章と翻訳指示をOpenAI APIへ送信します。
OpenAI APIキーは保存しません。

Ollamaモードでは、翻訳リクエストをユーザーのPC上のローカルOllamaへ送信します。

広告、アクセス解析、開発者によるテレメトリは実装していません。

詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

# Page AI Translator v1.0.0

v0.9の修正版です。

## 修正1: サイドバーのショートカット

`Alt + Shift + P` はWindows版Firefoxのメニューアクセスキーと競合する環境があるため、

`Ctrl + Shift + .`

へ変更しました。

manifest上では `Ctrl+Shift+Period` として登録しています。

Firefoxの「拡張機能のショートカットを管理」から、ユーザー側で別のキーへ変更することもできます。

## 修正2: 翻訳文を次の翻訳の原文にしない

v0.9では、たとえば

1. 日本語へ翻訳
2. 日本語の訳文を表示したまま翻訳先を英語へ変更
3. ページ翻訳

とすると、画面に表示中の日本語訳を英語翻訳の入力として扱う場合がありました。

v0.9.1では翻訳プロファイル
（翻訳先言語・訳し方・専門用語設定・追加ルール）
が切り替わる直前に、現在表示している旧プロファイルの訳文を
保持済みの原文へ戻してから新プロファイルを読み込みます。

そのため、

`原文 → 日本語`

を表示したまま英語へ切り替えても、

`日本語訳 → 英語`

ではなく、

`原文 → 英語`

になります。

旧プロファイルの保存キャッシュは削除されません。

## 確認項目

1. ページを日本語へ翻訳
2. 翻訳文を表示したまま翻訳先を英語へ変更
3. ページが原文表示へ戻る
4. ページ翻訳を実行
5. 原文から英語へ翻訳される
6. 翻訳先を日本語へ戻す
7. 保存済み日本語キャッシュを「翻訳文を表示」でAIなしに復元できる
8. `Ctrl + Shift + .` でサイドバーを開閉できる

## v0.9.2 → v1.0.0 RC1

専門用語設定の表示文言を多言語対応に合わせて修正しました。


## v1.0.0 RC1 release hardening

- OpenAIモードは翻訳対象のWebページ本文をOpenAI APIへ送信します。
- OpenAIモード初回利用時、Firefoxの `websiteContent` 任意データ送信許可を求めます。
- Ollamaモードはローカルの `127.0.0.1:11434` を使用します。
- OpenAI APIキーは保存しません。
- Firefox 140以降を対象にします。
- 詳細は `PRIVACY.md` を参照してください。


## v1.0.0 RC2

選択範囲翻訳の取得方法を強化しました。

ページ側で最後の有効な選択範囲を記録するため、
サイドバーをクリックした際にFirefoxが現在のSelectionを失っても
選択範囲翻訳を継続できます。

OpenAIモードでは、選択範囲を確保してからFirefoxの
Webサイト内容送信許可を確認します。


## v1.0.0 RC3

Firefoxでは `permissions.request()` の前に別のPromiseを `await` すると、
ユーザー操作ハンドラーとしての資格が失われます。

RC3ではOpenAI翻訳ボタン操作時、
同期的な入力チェックの直後に `permissions.request()` を呼びます。

選択範囲翻訳はRC2の選択スナップショットを維持しているため、
Firefoxの許可ダイアログが先に表示されても選択範囲を復元できます。


## v1.0.0 RC4

UIを最終整理しました。

- AI翻訳完了後は自動的に翻訳文を表示します。
- 選択範囲翻訳完了後も自動的に翻訳文を表示します。
- `翻訳対象を確認` ボタンを削除しました。

翻訳対象数・未翻訳文字数・ページ状態は自動取得されるため、
確認専用ボタンは不要になりました。
